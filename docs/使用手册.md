## 1. 快速启动

### 环境要求

- Node.js ≥ 18（本项目在 22.x 上开发验证）
- npm（随 Node 附带）
- Windows / macOS / Linux 均可（Web 版）；桌面端目前仅发布 Windows x64 / arm64 安装包

### 启动步骤

```bash
cd E:/06.AI_Agent/03_Resume-pan/app
npm install          # 首次运行需要；node_modules 已存在则跳过
npm run dev          # 启动开发服务器
```

启动后浏览器打开终端里打印的地址，默认 **http://127.0.0.1:5173**。

> ⚠️ Windows PowerShell 5.1 不支持 `&&` 分隔符，请分行执行：
> ```powershell
> cd E:/06.AI_Agent/03_Resume-pan/app
> npm run dev
> ```

### 全部命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 启动开发服务器（5173 端口，被占用时自动 +1） |
| `npm run build` | 类型检查 + 生产构建，输出到 `app/dist` |
| `npm run preview` | 本地预览生产构建（4173 端口） |
| `npm run typecheck` | 仅做 TypeScript 类型检查 |

首次 `npm install` 若在 Windows 上报 `Cannot find module '@rollup/rollup-win32-x64-msvc'` 或 esbuild 相关错误（安装脚本被文件锁中断所致），补一条：

```bash
npm install --save-optional @esbuild/win32-x64@0.21.5 @rollup/rollup-win32-x64-msvc@4.64.2
```

## 3. 核心流程：做一份简历

从模板到导出，完整链路只需四步：

1. **挑模板** —— 进 `/templates`，6 种章节标题版式横向平铺（色块 / 下划线 / 竖条 / 图标线条 / 极简黑白 / 彩色文字），点卡片「预览模板」看大图，满意点「使用模板」。颜色进入编辑器后再用「样式 → 主题色」自由挑选。
2. **填内容** —— 自动进入编辑器。每个模块都预填了 `XX / XXX` 样式的引导文案，照着替换成自己的信息即可；不需要的模块点隐藏开关即可。
3. **调样式** —— 左侧竖栏的四个设置面板（模板 / 文字 / 样式 / 间距）随时可开合。
4. **导出** —— 右上角「下载简历 ▾」，选**矢量 PDF**。

> 💡 打开 `/editor/sample-resume` 可以直接查看一份内容完整的示例简历，用来熟悉编辑器各项功能最快。

## 4. 编辑器详解

编辑器分为四个区域：**顶栏**（重命名 / 保存状态 / 导出）、**左侧设置竖栏**、**中间预览区**、**下方编辑区**（模块导航 + 表单）。

### 4.1 左侧设置竖栏

默认收起，只显示四个图标；**单击图标展开对应面板，再击同一图标收起**，点其它图标直接切换分组。

| 面板 | 能调什么 |
|---|---|
| **模板** | 6 种版式风格（线框预览图）。只切换外观与版式，**不改动已填内容与模块顺序** |
| **文字** | 简历语言（中/英）、5 款字体、字号 80%~115%（含 小/标准/大 预设） |
| **样式** | 8 色主题、头部布局（居中 / 居左 / 平铺）、信息展示（图标 / 文字 / 纯内容） |
| **间距** | 模块间距、行间距、左右 / 上 / 下边距五个滑杆 + 「恢复默认间距」 |

### 4.2 模块导航与内容模块

预览区下方一排**进度圆点 + 模块名**：已填的模块圆点为实心，一眼看出完成度。

- **切换**：单击模块名切换下方表单。
- **排序**：直接**拖拽**模块换位（拖动时出现主题色插入线）；或把鼠标悬停在模块上，用浮出的 `‹ ›` 微调。
- **显示 / 隐藏**：悬停浮出控件里的开关。隐藏的模块不出现在预览与导出 PDF 中，内容保留不丢。
- **重命名**：悬停控件里的铅笔图标（修改模块名会同步更新简历上的标题）。
- **添加 / 删除**：末尾「+ 添加模块」新增自定义模块；自定义模块悬停控件里有垃圾桶，可彻底删除。

11 类内容模块：基本信息、教育背景、专业技能、工作经历、实习经历、项目经历、校园经历、获奖情况、科研经历、自我评价、自定义模块。

- **基本信息**：姓名、出生日期（可只显示年龄）、性别、工作年限、求职意向、电话、邮箱、政治面貌 + 自定义字段（可配图标）。头像支持 JPG/PNG，≤1MB，上传后按 **4:5 竖版**裁剪（可拖动、缩放）。
- **条目式模块**（教育/工作/实习/项目/校园/获奖/科研）：每条一张卡片，名称、角色、起止时间（勾「至今」自动隐藏结束时间）、富文本描述。支持上移 / 下移 / 删除。
- **富文本编辑**：加粗、斜体、有序 / 无序列表、缩进；支持 **Ctrl+B / Ctrl+I** 快捷键；**直接粘贴 Markdown**（`- 列表`、`**加粗**`、`1. 有序`、`*斜体*`）会自动转换。

### 4.3 预览与缩放

- 预览默认 **80%** 缩放；右下角工具条可 `-` / `+` 微调或从预设档位（50%~150%）选择。
- 分页是真实的：内容按 A4 纸张逐块排版，放不下自动续排到下一页；长模块（含单条超长经历、长技能清单）也能跨页续排，不会丢内容。
- **智能一页**：当内容超过一页时，第一、二页之间会出现「✦ 智能一页」悬浮按钮，点击自动压缩间距与字号，直到排进一页（已达一页时会提示）。

### 4.4 顶栏

- **简历名**：单击可内联重命名（Enter 提交、Esc 取消）。
- **保存状态**：所有修改实时写入本机，停止输入 600ms 后显示「✓ 已自动保存」。
- **下载简历 ▾**：见下一节。

## 5. 导出 PDF：矢量版与图片版的区别

「下载简历 ▾」提供两种格式：

| | **矢量 PDF（推荐）** | **图片版 PDF（兼容模式）** |
|---|---|---|
| 原理 | 浏览器打印通道，文字是真实文本对象 | html2canvas 位图截图 |
| 放大效果 | **无限放大不模糊** | 放大变虚 |
| 文字 | 可选中、可复制、可搜索 | 不可选中 |
| 文件大小 | 较小（约 240KB） | 较大（约 1MB/页） |
| 操作 | 优先由本地渲染服务（端口 8790 起）自动下载；服务不可用时才回退到打印窗口 | 自动直接下载 |

**矢量版操作步骤**：点「矢量 PDF」即可自动下载——开发模式下 Vite 插件会自动拉起 `tools/export-service.mjs`（需本机 Chrome / Edge），桌面版则自带 Chromium，不依赖系统浏览器。若渲染服务不可用，才会回退到浏览器打印窗口：在「目标打印机」选 **「另存为 PDF」** → 保存，建议的文件名就是简历名。

> ⚠️ **打印预览发灰不是 bug**（仅回退到打印窗口时适用）：如果目标打印机选的是黑白打印机（如 Deli 激光打印机），预览按打印机能力渲染，整页会是灰的；换成「另存为 PDF」后即为彩色。用黑白打印机纸质打印时灰白是硬件限制。

> 💡 选过一次「另存为 PDF」后，Chrome 会记住，下次默认就是它（同样仅适用于打印窗口兜底路径）。

## 6. 数据存储与备份恢复

### 6.1 数据存在哪里

纯前端应用，**数据全部保存在本机浏览器的 localStorage**，不上传任何服务器。属于 `http://127.0.0.1:5173` 这个源：

| localStorage 键 | 内容 |
|---|---|
| `xl-resume-data` | 全部简历（内容 / 样式 / 模板选择 / 模块顺序） |
| `xl-resume-auth` | 本地用户身份（昵称、ID） |
| `xl-migrate-*` | 一次性迁移标记（可忽略） |

物理落盘位置（Windows Chrome）：`C:\Users\<用户名>\AppData\Local\Google\Chrome\User Data\Default\Local Storage\leveldb\`（LevelDB 格式，建议用应用内功能或 F12 查看）。

### 6.2 三条必须知道的原则

1. **换浏览器 / 换电脑 / 换端口（如 localhost 对 127.0.0.1）= 另一份独立数据**；
2. **无痕窗口不落盘**（降级为内存存储），关窗即失；
3. **浏览器「清除浏览数据」会连它一起删**——清理前先导出备份。

### 6.3 备份与恢复（账户中心）

进 `/account` → 「数据备份」区块：

- **导出备份**：下载 JSON 文件（文件名如 `Resume-Pan-备份-20261008-2231.json`），包含全部简历与本地身份。
- **导入备份**：选择备份文件 → 确认「导入并覆盖」（有不可恢复警告）→ 自动刷新，数据恢复。
- 区块上实时显示当前简历份数，方便导出前核对。

### 6.4 手动备份（备用方案）

F12 控制台执行：

```js
copy(localStorage.getItem('xl-resume-data'))   // 全部简历已复制到剪贴板
```

恢复：

```js
localStorage.setItem('xl-resume-data', '粘贴备份内容')
location.reload()
```

## 7. 常见问题 FAQ

**Q1：5173 端口被占用？**
Vite 会自动换到 5174、5175…，以终端打印的实际地址为准。

**Q2：PowerShell 里 `cd xxx && npm run dev` 报错？**
Windows PowerShell 5.1 不支持 `&&`，用 `;` 分隔或分两行执行。

**Q3：我的简历怎么不见了？**
按 6.2 节排查：是否换了浏览器 / 用了无痕窗口 / 地址从 `127.0.0.1` 变成了 `localhost`（或端口变了）/ 清过浏览器数据。数据没有丢在服务器上——它只在本机这个浏览器里。

**Q4：重装依赖后构建报 rollup / esbuild 模块缺失？**
见 1 节末尾的补装命令（Windows 平台二进制被文件锁中断所致）。

**Q5：打印预览是灰色的？**
目标打印机选了黑白打印机。选「另存为 PDF」即为彩色，见第 5 节。

**Q6：两种 PDF 选哪个？**
发给 HR / 上传招聘系统 → **矢量 PDF**（清晰、可被机器解析文字）；只在兼容性要求极高的旧环境打开 → 图片版。

**Q7：编辑器里字体和导出 PDF 里的不完全一样？**
矢量导出使用你系统上安装的字体渲染。在编辑器「文字 → 字体」里选择系统已安装的字体（如思源黑体），导出效果即与预览一致。

### 8.3 存储键与数据模型

| 键 | 说明 |
|---|---|
| `xl-resume-data` | zustand persist：`{ state: { resumes: Resume[] } }` |
| `xl-resume-auth` | `{ state: { user: { id, nickname, createdAt } } }` |

## 9. 已知限制

1. **数据仅存于单浏览器本地**——没有云端同步；跨设备请使用备份文件的导出 / 导入。
2. **矢量导出依赖本机 Chrome / Edge（Web 版）或内置 Chromium（桌面版）**——渲染服务不可用时才回退到打印窗口、需手动选「另存为 PDF」；Safari 等对打印支持较弱的浏览器建议改用图片版。
3. **图片版 PDF 是位图**——放大到较高倍数会变虚，正式投递请用矢量版。
4. **单条经历超过一页时**会跨页续排，但一条内的单个列表项仍不可再拆分。
5. **模板切换只换外观**——6 种章节标题版式共享同一份数据模型，不做内容差异化。
